# Physical Android evidence
Freeze device models (4GB low / 8GB mid), OS, page size, resolution/refresh/brightness, thermal start, battery and fixture checksums before a run. Use dedicated test devices with no personal data. Install the exact candidate separately; collect_android.py verifies the installed APK checksum and rejects emulator. Execute 10k / 100k / 1M feature workloads with map-first launch, pan/zoom, snap/edit, import/export and 30-minute active soak. Record renderer-specific FrameTimeline/Perfetto and Rust snap latency separately: gfxinfo alone is not native map frame evidence. Record p50/p95/p99, actual process RSS, GPU memory where measurable, battery drain and thermal state. Use pre-agreed thresholds (mid cold usable shell p95 <=2000 ms; frame p95 <=16.7 ms; snap p95 <=50 ms; low/mid RSS <=512/768 MiB). Distinguish process-cold launch from first usable map. Raw harness does not certify a gate. No device connected to CI by default.
