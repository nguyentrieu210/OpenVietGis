## W3 workbench candidate
Import Workbench from the package or dedicated source boundary. Dockview React 8.10.0 (MIT) wraps registered trusted host panels. Same-window floating only; no browser or native popout capability. Layout is local, account/project/workspace scoped, versioned and bounded. Unknown renderers and malformed/popout layouts fall back to a preset. Renderer `always` preserves tested synthetic canvas state across moves. Explicit reset may remount panels; host must provide canReset and veto with unsaved edits. Scope change intentionally remounts. No real map integration yet. Production host should lazy-load the workbench; isolated combined demo bundle is not a production benchmark.

## W4 GIS/CAD UI
Import from `@openvietgis/ui-react/gis`. Includes LayerTree, Legend, CrsSelector, SymbolPreview, SymbolEditor, ColorRamp, CoordinateInput, SnapToolbar and PropertyEditor. Controlled host inputs and explicit callback intents; no direct API calls, projection, geometry writes, snapping math or renderer replacement. Scope styles to component classes. CRS catalog/axis policy, permission flags, data and revisions come from trusted host. ColorRamp is a linear sRGB preview, not the classification engine. Host handles conflict checks, permission enforcement and existing style/snap services. Demo is isolated; production adapters and parity remain pending.
