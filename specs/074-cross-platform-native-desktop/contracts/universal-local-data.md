# Universal Local Data Engine contract — R3
One project has one authoritative writable transaction domain. Existing per-layer GeoPackage files remain the legacy implementation until a coordinated SPEC 073 migration is qualified. A candidate unified store must not receive production or managed data. Never use SQLite ATTACH/WAL as proof of atomic cross-file transactions. Preserve canonical UUID, source CRS, revision/tombstone and operation receipt semantics. Storage/schema ownership remains shared, not desktop-specific. Standard GeoPackage interchange is a separately tested adapter; an internal SQLite database is not automatically a GeoPackage.
Project view metadata may be stored separately because it is non-authoritative; explicit revision, atomic replacement, known schema, capped length, valid layer references, safe backup. Keep geometry/attributes separate from style. Schema edits require validating existing rows; the existing shared schema operation clears undo history and must be explicitly confirmed.
Provider registry advertises direct read-only / import copy / edit separately, supported CRS, format and limits. Files opened by scoped native grants; external changes invalidate read handles. No renderer-provided SQL or paths; virtual joins use typed allowlisted plan, explicit cardinality and bounds. No automatic writeback or egress. GDAL/OGR/PROJ, DuckDB, remote COPC, ECW and native CAD integrations are gated on exact license, dependency, driver and hostile-file qualification. No implied full format parity.
Maintenance reads integrity and index health, reports failure, never silently repairs or discards data. Compaction and migration require a verified backup, isolated staging and cancellation/recovery. Cross-layer transactions use single SQLite transaction with FK and RTree changes, stable mutation identity and expected revision; any invalid row rolls back all rows. A committed response lost on restart must replay the same receipt, not apply again.
Large workloads are stretch targets: 100M vector, 100 GB raster, 1B points; qualification records exact dataset/driver/device and bounded output/memory. No whole layer transfer. Existing W2 resource profiles and W4 managed lease gates remain.
