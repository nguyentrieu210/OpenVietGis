## Eleventh source checkpoint — bounded public HTTPS range and remote TIFF
- New optional `remote-range` feature (off by default), shared Rust HTTPS byte-range transport with no proxies, redirects, URL credentials, query strings, explicit non-443 ports, IP literals or private/non-public IPv4 destinations. DNS results are pinned to TLS hostname; IPv6/dual-stack results are rejected by this conservative profile. Requires exact 206 Content-Range, Content-Length, strong ETag and If-Match, identity encoding. Limits: 128 GiB source length, 64 MiB successful/requested range budget and 128 requests per reader, 8 MiB block cache, 1 MiB blocks, 90-second cooperative deadline plus request timeouts. DNS and in-flight blocking HTTP cancellation are not preemptive; no global multi-session bandwidth quota or network sandbox qualification.
- Restricted classic little-endian tiled TIFF decoder (uncompressed unsigned 8-bit grayscale, contiguous, 1024x1024 max block, 262144 max tile entries), bounded metadata and offset arithmetic. Optional GeoTIFF PixelIsArea north-up 4326/3857 metadata. Reads only selected byte ranges; refuses compressed TIFF, BigTIFF, unsupported pixel formats. This is a limited remote tiled TIFF profile, not full COG validation/overview/reprojection/map rendering. No full-file fallback.
- Desktop native IPC and explicit opt-in panel for HTTPS inspect and source-native block preview, revision via ETag/length and cancellation. URL remains session UI state; no auto-fetch at startup or persisted source. Each block request reopens reader (no cross-request cache). Scope checks workspace before/after read. No production qualification; renderer supplies explicit public URL, not an opaque persistent grant.
