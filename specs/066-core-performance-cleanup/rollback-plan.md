# Recovery
Record pre-change commit, production digest, config versions, database schema version, backup/restore evidence and retained client assets. Use additive expand/contract migrations only if necessary, validate old/new clients and rollback compatibility. Revert logical cleanup commits on regression; never reconstruct deleted source by hand. Keep previous immutable artifact until acceptance and restore test pass. Release via existing deployment mechanism after staging smoke. Abort on auth/data/CRS failure, startup loops, 5xx/health failure, missing artifacts, or agreed budget regression; revert app digest/config without deleting volumes. For incompatible DB change stop rollout and follow tested recovery plan with owner approval. No prod pruning or deployment performed by writing this spec.
