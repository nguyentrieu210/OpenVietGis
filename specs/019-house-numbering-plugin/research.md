# Research and decisions
- **Source:** [Grill](../../docs/grill-house-numbering-plugin.md) contains immutable legacy blob references and HN01–13 mapping.
- **Decision: module boundary.** Preserve official R014 manifest compatibility. Generic extension registration currently lacks lifecycle/event execution and command authorization verification. Establish generic capability contract and prove absence/second-module regression; do not add House Numbering names to Core. Alternative: separate legacy application rejected.
- **Decision: typed model + Core geometry refs.** Address relation/unique approval/atomic transactions require typed module tables rather than arbitrary JSON records. Geometry stays in Core spatial sources linked by project-scoped feature IDs, with transactional changes through supported contract. Alternative: duplicate geometry store and disjoint writes rejected.
- **Decision: pure numbering policy.** Along-route measure and side derived only from a declared projected CRS/ordered route; no geolocation guesses. Parse prefixes/base/suffix conservatively; existing unparseable values retained as evidence. Gap first then suffix, parity/state/reserved locks explicit. Alternative: sequential generator alone rejected.
- **Decision: governance.** A sealed rule version carries authority reference or draft-only status; no automatic official issuance. Real PII and legacy data remain gated; verify actual applicable local rule and templates during authorized release. Alternative: assuming legacy BRD is current law rejected.
- **Decision: privacy.** Restrict data at server and storage; do not use generic record list to hold personal data; redacted exports whitelist safe fields and scan outputs. Alternate broad legacy access rejected as incompatible with multi-tenant policy.
- **Decision: concurrency.** Immutable preview token includes revision, input snapshot and expiration; commit atomically with server-side revalidation. Number uniqueness enforced at persistence. Deactivation retains data. Do not use a series of independent POST calls.
- **Decision: import and reconcile.** Idempotent source fingerprint, explicit CRS/policy, reversible staging, old-number unique match first. Uncertain matches are manual.
- **Decision: offline and documents.** Reuse actual verified field and cartography/artifact gateways, no synthetic success. Missing imagery labeled; template authorization separate.
- **Dependency assessment (actual VPS 2026-11-21):** audit 018 gaps G003 graphical editing, G004 external retrieval, G005 offline, G009 processing, G010 artifact backup. Candidate R014 generic API lacks required revision/deactivation. G001 requires exact-candidate review before promotion. Pure domain tests independent; integration/release stays blocked until verifiable gates.
