# SPEC 071 — Dynamic Plugin Platform & Industry Workspace
Dev-only; extends official module registry, SPEC 051, 057, 067/068 and 070. Core GIS must not expose a permanent domain toolbar.
E01 typed contribution registry; E02 plugin manager/marketplace discovery; E03 optional movable toolbar; E04 dockable/resizable workspace; E05 map-tool SDK; E06 processing SDK; E07 lifecycle cleanup; E08 house-numbering workspace; E09 dashboard based on real scoped data; E10 house-numbering map actions; E11 permission isolation; E12 scoped workspace persistence; E13 developer SDK; E14 multi-plugin integration and regression.
User stories: open GIS with no domain UI; launch activated plugin from Plugin menu; choose a workspace side and optionally display a movable toolbar; navigate house-numbering workflows without losing map context; close plugin and restore core filter/style/search; switch project without leaking local UI state. No mutation without server authorization. Do not infer official address assignment from survey status.
Acceptance: no fixed domain toolbar, no domain API before open, UI commands vanish on activation removal, project/account isolation, close resets domain contributions, all existing workflow routes accessible, keyboard/resize/drag/reload regression, no live change. Full multi-plugin runtime, SDK and processing isolation require separate acceptance.
