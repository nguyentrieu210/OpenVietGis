# Stable Acceptance — evidence policy

Implementation scope: Evaluate exact candidate using existing fail-closed release preflight; preserve NOT_RUN/blocked independent gates until evidence exists. No version/tag/live change.

Run evidence: Local gate results, isolated integration results, artifact integrity and release preflight result. See [candidate runbook](../../docs/community/CANDIDATE_RUNBOOK.md) for exact candidate logs. Local checks are not release approval.

Open: All CQ-P0/claimed P1 acceptance, native Windows QGIS, real CAD/3D, OIDC, restore/rollback and independent approvals.
