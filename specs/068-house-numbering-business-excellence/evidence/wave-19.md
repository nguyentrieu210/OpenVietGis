# Wave 19 — parcel identity and stable address lookup

- Migration HN 0019 creates a separate scoped parcel identity keyed by the immutable source/feature pair, with reference and evidence, and a many-to-many parcel/building association event ledger. No inference of ownership or cadastral legal validity. Existing free-text parcel_ref is retained and not automatically merged or migrated. Scope FKs, forced RLS and insert-only runtime grants protect history. The association state machine enforces revision sequencing, independent confirmation/rejection, detach and reobservation. Parcel geometry digest must be ready and unchanged between observation and confirmation. This is a reviewed association, not spatial containment adjudication; building geometry is not pinned by this ledger. No automatic change to allocated numbers and no new approval prerequisite for optional parcel data.
- Added list/register/link/review endpoints, typed frontend and parcel panel in Registry. Registration and observation require survey access, other transitions require approve, all writes require CSRF. GIS Point cannot be used as a parcel; ready Polygon is required. UI shows geometry currency and history, with polygon navigation. Geometry split/merge and parcel legal lineage remain open.
- Added authenticated stable address lookup by allocated number UUID, independent of issuance UUID. Requires exactly one currently registered, nonvoid certificate with unchanged approved number, active eligible building and confirmed matching road. Replacement resolves to the new certificate via the same address ID, while old certificate-specific QR remains invalid. No public lookup, QR image generation or identity preservation across renumbering; number UUID is a stable identity only for the same allocation.
- Real disposable PostGIS fixture migrated through HN 0019 and passed exact SQL for unique parcel source/feature, independent review, multiple parcel associations, CAS, detach/reobserve, immutable grants and project RLS. Stable lookup SQL passed initial certificate, void gap, same-number replacement and scope denial; prior proposal, primary entrance, staff KPI and issuance regressions passed. Module Rust HTTP compile, TypeScript, Python syntax, architecture and diff checks passed. Full new HTTP binary and browser flows not run.
