# UI contract for first-party plugins
Import Button, Input, Select, Textarea, Actions, ScrollArea and TableScroll from apps/web-next/src/ui/primitives. Use Modal from studio-ui with explicit size; supply a scoped resizeScope for user-adjustable layouts and optional footer for fixed actions. Use existing Splitter and PluginWorkspace for docks. Do not add viewport-based minimum widths to modal descendants. Use minmax(0,1fr) grids and wrap action rows. Tables may scroll inside TableScroll. Theme values use --ovg-ui-*; GIS-specific legacy --ovg-* tokens bridge them. Tailwind uses the ovg: prefix and no Preflight. Do not set map imagery or print content to theme colors. Test keyboard, screen width, permissions and storage scope. These imports are internal first-party API, not a stable third-party sandbox SDK.
