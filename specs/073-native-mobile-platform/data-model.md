# Mobile data model — proposal
LocalWorkspace(id, mode local|managed, server_id nullable, owner_scope nullable, created_at, schema_version). Local mode never gains tenant authority by ID collision.
ManagedScope(server_origin_id, account_id, org_id, project_id, ACL epoch, offline lease expiry, manifest versions); cache/encryption key per scope; scope part of all managed keys; never store service credentials.
Source(id, workspace_id, kind, source_uri_handle, fingerprint, source_crs, capabilities, provenance); Layer(id, source_id, style, visibility, order, revision); Feature(stable_id, layer_id, geometry, properties, revision, tombstone) with GeoPackage schema/RTree and explicit CRS.
ChangeSet(id, scope, base_revision, operation_ids, author, status draft|committed|queued|acknowledged|conflict|blocked, timestamp); Outbox(operation_id, scope, exact_payload_hash, base_revision, retry_state, receipt); SyncCursor(scope, cursor, snapshot_revision, acl_epoch). Atomic local mutation + outbox; receipt/revision + cursor atomically applied. Same operation ID cannot change payload. Local undo after acknowledged edit creates new audited change.
SurveySession(id, workspace_id, consent_flags, start/stop, device/provider); Observation(id, geom, crs, time, horizontal/vertical_accuracy, fix_type, correction_source, attributes); TrackSegment and Attachment(hash, media_type, private_uri, metadata_policy, upload_state); do not infer fix quality. Attachments scoped and bounded.
OfflinePackage(id, scope, content_hash, manifest, expiry, byte_size, status); TileArchive(id, source, attribution, format, bounds, zoom_range, quota, hash); no secret URLs in export/log.
PluginRelease(existing manifest_id, extension_key, version, SDK range, platform capabilities, signature, assets digest); Activation(existing organization/project record, revision, status); MobileContribution(schema version, slots, bounded UI graph, command IDs, required caps); Entitlement(server-issued, scoped, expiry, signature; if approved). No separate marketplace identity.
Job(id, algorithm_id, parameter hash, input revision, CRS pipeline, runtime, progress, state, output/provenance); cancellation never publishes partial data. Diagnostics opt-in and redacted.
 
## Migration and retention
Version migrations in transactions with fixtures for previous supported versions, snapshot/rollback as appropriate; no destructive default on migration failure; recover read-only/export where permitted. Local personal files survive sign-out; protected managed cache locks on expiry/revocation and purges according to policy; unresolved edits stay inaccessible until reauthorized, no export bypass. Offline revoke cannot be instantaneous without connectivity; document maximum authorized lease. On online revocation, close plugin and invalidate scoped sessions/cache. No cross-account outbox replay.
