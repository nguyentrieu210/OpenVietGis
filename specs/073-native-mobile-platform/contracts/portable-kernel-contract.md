# Portable kernel contract v2 — proposed
Owner E02; W0 inventory T001/T008 plus kernel T009–T011. Preserve current ovg-spatial, ovg-core, ovg-processing, ovg-sync and server contract; no wholesale fork. 
## Dependency direction
Flutter UI -> Dart SDK -> generated FFI -> portable engine -> typed adapter traits -> platform implementations. Server adapter can depend on SQLx/PostGIS/Axum; portable crates MUST NOT. Domain modules depend on public contracts, never reverse. No platform filesystem, identity, DB or network globals in pure algorithms.
W0 inventory must enumerate symbol/path, current caller, dependencies, CRS/geometry semantics, disposition reuse/extract/adapter/server-only, fixture and owner. Freeze cargo feature graph for Android and iOS; cargo tree -e features and cargo metadata proof excludes SQLx/Postgres/Axum, including transitive features; preserve Web/Server contract tests. Baseline crates are candidates, not assertions of portability.
## Interface rules
Opaque generation-tagged handles scoped to engine/workspace; no cross-session use, stale/closed handles return typed error. Explicit acquire/release and cancellation; idempotent dispose; no raw pointer or unbounded vector through public host. Catch panics at FFI boundary; panic is terminal for affected session, never report partial commit as successful. Worker threads limited; no blocking native work on Flutter UI. Cancellation before commit aborts transaction, after commit returns receipt; retry queries receipt. 
Batch envelope: schema/version, scope, source/layer/revision, CRS, encoding, row count/bytes, continuation, request epoch. Baseline WKB and typed arrays, 4 MiB or 4096 features per batch (whichever first); oversize feature explicit bounded stream or reject. Ownership transfers only with documented lifetime; consumer releases once; cancellation/close waits for outstanding readers or safely invalidates. Measure copy count and bytes; Arrow/GeoArrow only if measured improvement, not a mandatory second format. 
## Correctness
Stable algorithm IDs, explicit units/CRS, geometry dimensions and tolerance. PostGIS-dependent operations use local adapters only within independently verified profile; no silent online substitution. Preserve source IDs and lineage where contract permits. Compare server and mobile with oracle, topology equivalence plus fields and counts; not byte equality of polygon ordering. 
## Acceptance
Build portable target, dependency guard, stale handle/parallel close/cancel/panic/oversized input tests, differential fixture tests and existing server regression. W0 produces actual path-level inventory and owner DAG before extraction. No task closes merely on this document.
