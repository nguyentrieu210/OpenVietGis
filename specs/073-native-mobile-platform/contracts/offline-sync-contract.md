# Managed offline storage and sync contract v2
Owners E08/E10; reuse actual managed_sync.rs commit/receipt, delta and bootstrap contracts; W0 records exact request/response/limits/revision types. Independent local workspaces remain standard portable GeoPackage, never inherit server authority.
## Storage boundary
Managed workspace uses an encrypted private SQLite/GeoPackage-compatible internal store (SQLCipher candidate, qualify build/license; otherwise approved equivalent). Plain GeoPackage alone is not encryption. One writer; feature, revisions, journal, outbox, receipt and cursor share one ACID transaction domain. App UI preferences can live in separate Drift DB but cannot be authoritative for sync; separate attachment files use staged encrypted blob + hash + fsync + atomic rename, DB reference committed only after durable blob, garbage collector removes unreferenced blobs after recovery. 
Per server/account/org/project scope key wrapped by OS keystore; authenticate before unwrap. WAL, journals, temp, index, thumbnails, tiles, photos, caches and backups must not expose protected plaintext; prohibit OS backup of managed data, private temp/streaming export only with current authorization and explicit user intent. Lock on logout/lease expiry/revoke, zeroize keys and discard scoped render/FFI buffers as far as platform permits. Cryptographic erase on approved purge; no deletion of independent local files. Document limitations on screenshots, rooted devices and OS memory; no guarantees of complete memory erasure.
## Offline lease
Mandatory for protected offline packages. Signed lease binds subject, server instance, org/project, revision/ACL epoch, package digest, allowed ops, key ID, issue/expiry, and device/session as applicable. Default maximum 24h proposal, server may shorten. Trusted server time + monotonic clock while same boot; after reboot or unreliable clock fail closed until revalidated unless reviewed trusted-time mechanism. Reconnect rechecks current permissions before uploads. Offline revocation cannot be instantaneous; bounded lease and visible expiration. 
## State machine
Workspace: absent -> downloading -> verifying -> ready -> dirty -> syncing -> ready/conflicted/locked. Snapshot downloaded into staging; verify signed manifest/digest/schema/ACL epoch, atomically swap at consistent revision/cursor, retain pending outbox and rebase explicitly. Never advance cursor on partial page/failed transaction. 
Operation: draft -> committed locally/queued (same transaction) -> sending -> acknowledged | unknown | conflict | blocked. Unknown outcome -> query exact operation receipt before retry; same ID + exact canonical payload hash, never mutate payload after send. If receipt retention expired/ambiguous, block automatic replay and reconcile snapshot/history or user review. 409 -> classify feature revision, schema, tombstone/deletion, permission or geometry conflict; show base/local/server, manual merge/rebase creates new operation ID, links predecessor; no last-write-wins. 401 refresh once; 403/revocation lock; 429/5xx bounded jittered retry; invalid payload blocked. Preserve unresolved authorized edits until explicit resolution; no bypass export.
Delta: ordered scoped cursor, source/schema/content revisions, ACL epoch and tombstone; gaps -> consistent snapshot plus replay/rebase unacknowledged edits. Duplicate delta/receipt is no-op; cursor + applied data atomic. Attachments idempotent content hashes, authorization and bounded retries; orphan cleanup; no acknowledgment before required refs exist. Server retention contract must cover maximum retry window; otherwise block unknown replay.
