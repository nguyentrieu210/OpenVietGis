# Mobile rendering and resource contract v2
E04/E07/E13. MapLibre Native owns default map renderer; Flutter owns UI/gesture arbitration; Rust owns committed geometry and spatial queries; no second default GPU engine.
## Data flow
Local GeoPackage/RTree -> Rust viewport query keyed by workspace/layer/content/style/CRS/LOD -> bounded tile or feature batches (local MVT adapter preferred for large vector; small GeoJSON only within measured bound) -> native map adapter. Choose in W0 proven supported native source interface; no open localhost server by default; if loopback transport unavoidable, authenticate per session, bind loopback only, review security. WKB/typed buffers for edit/analysis, never roundtrip entire dataset through Dart. Renderer may simplify/quantize for display only; editing/snapping uses full-resolution authoritative geometry, explicit CRS transform. 
Camera updates coalesce at frame boundary; cancel stale queries by generation; cache invalidates only affected tiles/features/revision; selection/hover uses feature state, not full geometry reupload. Transient edit overlay and committed data separate. Touch map vs editing gestures explicit; one-finger select/drag, two-finger pan/zoom during edit where supported, accessible alternative and undo/cancel. Hit-test tolerance in screen pixels mapped to ground/CRS; reject stale hits. 
## Resource governor (initial proposed budgets)
Reference low 4GB RAM / mid 8GB RAM ARM64, physical devices fixed W0. Low RSS <=512 MiB, mid <=768 MiB; bounded cache 96/192 MiB, workers 2/4, native jobs 1/2, tile concurrency 4/8; reserve for UI/render/OS, measure actual peak including GPU where available. Low-memory/thermal signals reduce LOD, cache and workers; pause nonessential analysis, persist drafts; do not degrade stored coordinates. Cold shell p95 <=2s mid, frame p95 <=16.7ms at 60Hz defined profile, snap p95 <=50ms; low tier degrade display only and record p95/jank. Initial installed app budget <=250 MiB Android base (excluding user downloads), justify exceptions; 30-min soak and battery target from SC009. W0 freeze device model/OS/resolution/refresh/brightness/dataset geometry count and visible vertices/tile sizes, cold/warm definitions before benchmarking. 10M features, 100M points stretch. 1M source features != simultaneous 1M visible. 
Acceptance: map resize/rotate/background/low memory, pan/edit/snap, stale response, source switch, cache revision and copy count; real GPU/device evidence, no emulator FPS claim. Optional Arrow/wgpu justified by p95/RSS/battery/size improvements and correctness.
