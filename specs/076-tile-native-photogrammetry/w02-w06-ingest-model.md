# Ingest and camera-model checkpoint
JPEG staging copies original bytes in bounded blocks into a fresh job directory, inventories SHA256 and dimensions, rejects duplicate source paths and limits total bytes. Header validation only, not full JPEG decode or EXIF/RTK. File-picker paths must be host trusted and immutable while staging; partial jobs are not executable. COLMAP undistorted PINHOLE/SIMPLE_PINHOLE text import converts quaternion and translation to camera center and rotation, validates names and observations, and supports an explicit 3D similarity transform. No automatic geographic alignment; no claim that reconstructed coordinates are projected. Tests not yet executed. Reference https://colmap.github.io/format .
