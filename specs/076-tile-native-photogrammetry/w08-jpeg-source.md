# W08 JPEG source integration checkpoint
The file-backed reference pipeline can now decode selected undistorted JPEGs directly with bounded memory, bind a COLMAP pinhole model and explicit 3D alignment, read DEM windows and write GeoTIFF tiles. Stable order, dimension checks, conservative footprint filtering, decoded-buffer admission and no intermediate full-project raw RGB copies. A real tiny JPEG plus synthetic calibrated camera/DEM integration fixture is authored but not executed. Camera and undistortion outputs must be qualified and supplied by the host; no automatic reconstruction or RTK/GCP alignment yet. Decoder peak memory remains an estimate; selected whole images are decoded per tile (no region decode, cache or sandbox yet). No production capability enabled.
