# W10 streaming fused cloud DSM
Refactors strict PLY validator to stream verified rows to a consumer. DSM transforms local points using validated positive-scale proper rotation into a host-qualified metric grid, retains max Z per cell, minimum support and coverage gates, explicit plausible elevation interval, NaN nodata and atomic fresh raw float32 file with SHA256 receipt. No full point cloud allocation; raster buffers capped at 16M cells and configured work bytes. No ground classifier, interpolation, vertical datum conversion or validated survey accuracy. Input must be immutable and authorized. Tests authored, unexecuted.
