# Experimental Linux worker — qualification pending
The CPU sparse runner launches the internally generated COLMAP stages through bubblewrap, with network and PID namespaces, read-only system runtime and approved binary, writable private workspace, no inherited environment, deadline/cancellation and per-process address-space/file-size limits. The host must independently qualify the full immutable pack, protect the staging root and verify input hashes, enforce aggregate memory and disk quotas via cgroups/filesystem, and verify model completeness, quality and artifact provenance. Per-process prlimit is NOT aggregate memory or disk enforcement. No GPU, Windows or macOS execution enabled. Output logs are currently suppressed and must be replaced with bounded diagnostics. COLMAP output is a sparse model, not a georeferenced map. Exact CLI compatibility, bubblewrap availability and real-image execution are not verified. All production capability flags remain disabled.
