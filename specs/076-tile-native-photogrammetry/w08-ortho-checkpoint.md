# W08 reference orthorectification implementation
CPU inverse projection from north-up output grid and DEM through calibrated, undistorted cameras; bilinear RGB, optical-axis preference, nodata alpha, output/sample caps and rotation validation. Tests use synthetic nadir and nodata fixtures and are not run. Existing surface must be compatible with the camera metric frame. No georeferencing, terrain visibility/z-buffer, seamline optimization, exposure balancing, distortion handling, real decoder, provider execution, GPU, COG publishing, or real image acceptance yet. This is not a survey-grade product. No capability enabled.
