# W08 pipeline integration checkpoint
A reference CPU pipeline now connects adaptive halo partition, per-window raw float DEM reads, bounded calibrated RGB input, inverse camera projection, crop-to-core, GeoTIFF encoding, SHA256 storage and atomic revision publication. It renders sequentially, supports cancellation at tile boundaries, reports coverage and enforces output byte cap. Source input is pre-calibrated raw data with host-provided camera poses and projected metric CRS; no automatic flight image alignment. Raw RGB files loaded whole per selected tile (bounded, not region decoding); source footprint selection must be conservative. A synthetic file-backed tiled-vs-whole test and cancellation test are present, not executed yet. Not a COG export, not survey-grade, no desktop UI, no automatic checkpoint resume or actual COLMAP integration.
