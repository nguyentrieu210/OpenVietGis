# W13 cache and idle prefetch integration
Shared process RAM cache capped at 64 MiB, persistent direct-mapped slots per immutable preview, integrated in existing four-slot cancellable XYZ endpoint. Frontend schedules at most two neighbouring tiles sequentially after 700 ms idle, prefers latest pan direction, clips to source extent and aborts on move start/unmount. Reuses standard endpoint and returns/discards RGBA, not dedicated low-priority worker queue; visible requests share the same permits. Zoom heuristic may differ from actual MapLibre tile selection. No benchmark or UI execution. Persistent levels are lazy, no fully built pyramid.
