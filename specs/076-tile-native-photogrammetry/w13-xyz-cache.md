# W13 lazy persistent XYZ cache
RAM LRU (up to 64MiB) plus per-preview fixed 256 disk slots (~64MiB), keyed by canonical project preview path, manifest SHA256, algorithm version and XYZ. Disk record contains key and payload digest; misses and corruption regenerate from verified source, no source deletion. Direct-mapped disk replacement, not SSD LRU. Process-local write lock; cross-process writers and physical quota enforcement remain unqualified. Cache assumes immutable source artifacts and trusted local storage; it does not rehash source objects on cache hit. Lazy population across zoom levels, not a precomputed complete pyramid. Tests authored, unexecuted.
