# Quality and benchmark v2
W00 freezes reference hardware, fixture hashes, rights, control accuracy, comparable Agisoft version/settings, exact output GSD, density, completeness and thresholds before testing. Proposed reference profiles: 8 GB Lite CPU sparse/fast with validated DEM; 16 GB RAM/8 GB VRAM balanced NVIDIA; 32 GB RAM/12 GB VRAM survey workstation. Actual devices to record; no claim these are tested. Fixtures: synthetic calibrated geometry; real nadir, repetitive vegetation, oblique/urban, low texture, RTK/GCP with independent checkpoints, repeat flight; 100/1k/10k/100k image tiers. 100k stretch only; simulation not real execution.

Proposed initial qualification thresholds (not universal survey standards; tighten or revise with explicit ADR BEFORE benchmark): synthetic camera projection error <=0.1 px for deterministic transforms; registration >=95% on designated high-overlap fixture; median reprojection <=1 px; survey checkpoints >=10 independently surveyed points distributed over fixture with accuracy documented; XY RMSE <=2 GSD, Z RMSE <=3 GSD on designated suitable nadir fixture; p95 XY <=4 GSD and Z <=6 GSD; requested covered area >=98% for valid high-overlap ROI; tile vs untiled seam displacement p95 <=1 output px; color difference median DeltaE00 <=3 on stable overlap reference; DSM/DTM independent elevation threshold defined per terrain; no unsupported gap fill. Difficult scenes get separately frozen profiles, never retroactively relaxed to pass. Independent controls excluded from fit and tuning. No fixed survey grade label if evidence insufficient.

Performance targets, not achieved: base installer <=100 MB excluding packs; idle <=300 MB and launch <=3 s subject to shared shell measurement; 60 FPS reference at declared viewport with p95 frame-time reported; 2x throughput and 50% lower peak host RAM stretch against Agisoft ONLY at matched quality; record CPU/GPU/VRAM/SSD peaks and export time, transfer overhead and package size. At least three repeat runs, cold/warm distinct; report median and p95 for sampled latency with sample count (not meaningful tail from three runs). Full time includes ingest→validated output and optional export separately. No faster claim for poorer output. Benchmark raw logs and reproducibility recipe attached. Fault suite: worker kill, process tree memory overflow, GPU OOM, disk full, invalid CRS, corrupt cache, canceled task, stale lease, permission, disconnected graph. Valid prior manifest unchanged, no lost acknowledged results.
