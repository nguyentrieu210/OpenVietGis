# Tile contract — Revision 2 implementation subset
Eight independent layers: image, feature, geometry cluster, depth, spatial block, compute, storage, display. Layer-specific addressing must include project/revision/grid/schema; current in-memory TileId is only local to a single grid. Integer half-open core windows have exact disjoint coverage. Halo windows overlap and are clipped to extent. A tile may be split on either axis; fixed image resolution and quality settings cannot be silently reduced. Working set estimate includes halo; provider-specific bytes-per-pixel estimates require calibration. Impossible budgets fail closed. Global camera solution and CRS/grid origin remain shared; geometry changes invalidate dependent nodes even outside changed pixel extent.

Planned storage: immutable digest-addressed artifacts, atomic compare-and-swap manifest, revision references, dependency digests, provenance and garbage collection only after all references and active leases are gone. No direct updates to single published COG. Current implementation only partitions a 2D grid and identifies affected halos; no Octree, persistent storage, CRS or artifact publication yet.
