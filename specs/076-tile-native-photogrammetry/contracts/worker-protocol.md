# Provider and worker contract v2
Versioned typed capability: ID, protocol major/minor, build hash, supported operation/input/output/platform/driver, precision, limits, locality and license approval. Incompatible major rejected. Operation messages carry job/revision/node IDs, scoped read/write handles, bounded resource reservation, dependency digests, canonical options, deadline/lease and idempotency key. No arbitrary shell, SQL, network, unbounded paths or bytes on control plane. Workers run with constrained OS rights; untrusted file parsing isolated. Network disabled by default.

State QUEUED → ADMITTED → RUNNING → COMMITTING → SUCCEEDED; BLOCKED, RETRY_WAIT, FAILED, CANCELLED explicit. Pause at safe checkpoints or report unsupported; cancel process tree; stale lease may not commit; transient retry bounded. Commit CAS checks input revision and expected manifest. Progress events monotonic sequence with job/node/tile, actual completed/estimated units, telemetry and uncertain ETA. Distinct errors unsupported operation, missing pack, license, CRS, geometry, low overlap, disk/RAM/VRAM exhaustion, corruption, cancellation, permission, revision conflict. No auto-retry permanent errors.
