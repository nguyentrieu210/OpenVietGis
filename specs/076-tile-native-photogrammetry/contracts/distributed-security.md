# Remote worker and security v2
Remote is opt-in per project/job; show destination, data amount and scope before upload. Authenticated existing identity, least privilege, short-lived scoped leases, revocation, encryption in transit and checksummed chunked transfer; no implicit cloud fallback. Worker identifies exact build, model and hardware; coordinator verifies artifact digest, quality and lease before manifest CAS. Heartbeats, stale result rejection, retry limits and idempotent publication. Offline mode disallows network. Signed pack trust root and rollback protection; SBOM, dependency/model licenses and vulnerability scan. Hostile file, path traversal, zip bomb, malicious plugin, IPC origin, expired lease and unauthorized publish tests. Separate processes do not remove license obligations.
