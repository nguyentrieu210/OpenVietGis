# W13 Desktop prepared preview manager
Reuses trusted window/handle checks, one shared import/render lease, native folder dialog, bounded verified prepared-package snapshot, tile progress and cancellation, fresh private output staging and atomic directory rename with saved receipt. Completed preview receipts reload on project reopen. Four retained previews per legacy standalone project; no destructive cleanup. No viewer/map attachment, no unified-store backup integration, no disk-free-space probe or cross-process coordination, no raw-image reconstruction or GPU production lane. Cancellation is cooperative at tile/copy boundaries, not a hard process kill. No build or UI test executed.
