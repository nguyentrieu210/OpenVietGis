# W01 resource accounting checkpoint
Pure Rust admission pool supports atomic reservation of shared host RAM, CPU threads, scratch and output bytes, and separate GPU capacity per device. UMA allocations are charged to both the device ceiling and the shared host ceiling (one physical host allocation), not treated as independent physical pools. A single runtime lock must guard the pool. This is not OS memory containment. The snapshot recommendation and admission pool are not yet wired into an executing worker. Actual host probe, persistent overrides, Ultra profile, pressure policy, per-process telemetry, Job Objects/cgroups and macOS qualification remain open. No tests run in this checkpoint.
