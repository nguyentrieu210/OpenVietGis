# 3D Tiles checkpoint
Reference 3D Tiles 1.1 JSON generator for GLB leaves. Each leaf requires host-verified local Z-up metre bounds and rigid ECEF frame, right-handed orthonormal axes, bounded local extent. Computes enclosing root ECEF box, relative digest-only content URI, column-major transform. GLB's glTF Y-up coordinates are interpreted through the 3D Tiles Y-up to Z-up conversion. Host must verify the actual GLB digest and matching bounds, stage referenced content, derive frame from authoritative CRS and quantify projection linearization error. Flat leaves only; no hierarchical LOD, texture, nonlinear reprojection, streaming integration or independent Cesium validation. Tests not run.
