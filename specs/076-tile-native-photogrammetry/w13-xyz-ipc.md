# W13 desktop XYZ integration
Adds project-handle + preview UUID scoped IPC, four concurrent raster read permits, cancellation through existing request registry, fixed 256x256 RGBA payload (256 KiB). MapLibre custom protocol converts received RGBA to PNG locally, registers raster source with bounds and max source zoom 24, cancels stale requests on navigation/selection and disposes protocol on close. Overview still scanned once for extent. No persistent pyramid, cache or measured latency; source caps unchanged. Uses standard WGS84 UTM series, not qualified PROJ precision. Modern WebView AbortSignal.any required. No CI or actual desktop run.
