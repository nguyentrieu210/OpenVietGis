# W07 control network checkpoint
Connects marked-image GCP triangulation to weighted 3D similarity. Explicit unique control/check IDs, bounded robust triplet search, control residual consensus and independent XY/Z/max-3D quality gate. Failed checks return a failed report, not acceptance. Point identities, survey provenance, projected metric CRS and vertical datum must be trusted/verified by the host; duplicated physical points under different IDs are not detected. Configurable thresholds are not survey certification. Not full camera/point bundle adjustment, covariance-aware RTK/PPK or marking UI. Synthetic tests authored, unexecuted.
