# CPU orthomosaic preparation plan
Adds internally generated COLMAP image_undistorter and model_converter command plans from a host-selected sparse model. The intended output is dense/images and model-text/cameras.txt plus images.txt, usable with the calibrated JPEG source after independently validated alignment. No dense GPU required for this plan. This is command planning only; the Linux worker still executes sparse stages only. Host must qualify CLI options, execute isolated stages, validate output format (JPEG and undistorted pinhole), preserve input/output digest and verify geodetic alignment and DEM. No automatic end-to-end flight job claimed.
