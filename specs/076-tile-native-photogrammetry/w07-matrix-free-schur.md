# W07 matrix-free Schur checkpoint
Implements point elimination and matrix-free Schur application for 6x6 camera blocks, 3x3 point blocks and sparse 6x3 links. Cholesky point factors, camera-block Jacobi preconditioner, PCG, true residual convergence check and landmark back-substitution. Linear storage in cameras/points/links instead of dense camera matrix; explicit iteration and internal memory caps, cancellation. Caller must supply anchored, damped SPD normal equations and reserve input/allocator memory. This module is not yet connected to the nonlinear BA linearization, no hierarchical BA, no hardware benchmark. Tests written, not executed.
