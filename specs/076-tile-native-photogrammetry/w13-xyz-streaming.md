# W13 XYZ raster candidate
On-demand 256x256 Web Mercator output via per-pixel inverse mapping to WGS84 UTM source pixels. Bounded spatial bin index, grouped reads of selected immutable canonical GeoTIFF shards, hash and affine validation, transparent outside source, cooperative cancellation. Nearest-neighbour zoom-dependent sampling, not precomputed averaged overviews or a qualified PROJ warp. Maximum zoom 24; existing preview caps (64M source pixels, 300MiB output, 8192 shards, 20km) remain. At low zoom one request may read many shards; no persistent cache or performance evidence. Tests authored, not run.
