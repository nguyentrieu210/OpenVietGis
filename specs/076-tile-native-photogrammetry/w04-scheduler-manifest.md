# W04 checkpoint
In-memory bounded DAG scheduler: dependency readiness, unique lease, deadline, bounded retry (max 3 attempts), terminal state and rejection of late receipts. In-memory manifest store: immutable retained revisions, expected-head compare-and-swap, validated hash references, transitive dependency references retained by supplied metadata. This is not a durable artifact store; no SHA256 bytes verification, filesystem transaction, crash recovery, output atomicity with scheduler, GC, host worker integration or out-of-core paging. Full manifest copies are a prototype and must be replaced with bounded persistent indexes before large-dataset qualification. No W04 acceptance claimed.
