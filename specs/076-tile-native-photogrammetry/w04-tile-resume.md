# W04 per-tile restart journal
Adds resumable reference raster path. Immutable checkpoint namespace includes expected parent revision, host-verified input/build digest, grid and exact coordinate bits, tiling policy and all configured budgets. Each completed tile records window, digest, byte length and covered pixels after artifact publication; reuse verifies object SHA256 and exact expected window/length. Cancellation leaves head unchanged; restart can skip completed tiles. Corrupt records fail closed. Host must authenticate input fingerprint and protect source immutability and checkpoint metadata; no automatic fingerprint calculation, signed journal, GC, Windows crash qualification or power-loss test yet. Journal is not automatically pruned. Tests added, not executed.
