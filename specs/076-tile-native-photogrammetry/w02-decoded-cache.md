# Decoded image cache checkpoint
Byte-bounded per-source LRU with shared Arc buffers, no per-tile full RGB duplication. Cache entries are removed while actively selected, evicted before further decode, and reinserted after the batch. The sequential pipeline drops each batch before the next request; callers retaining batches outside the pipeline must separately account pinned bytes. Immutable host-verified source revision required; cache key is path within that source instance, not a cross-revision content cache. Metadata and decoded-byte limits are separate; no process RSS guarantee, no region decode or benchmark yet.
