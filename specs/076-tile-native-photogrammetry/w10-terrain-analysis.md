# W10 CHM and cut/fill analysis
Streaming raw float32 paired-raster calculations, exact matching metric UTM grid and declared vertical datum, hash verification, bounded buffers, explicit coverage/NoData and deadband. Cut/fill uses projected cell area and signed after-before, compensated sums; no extrapolation or uncertainty certification. CHM emits immutable raw float32 output; small negative inversion clamps to zero, large inversion becomes nodata, coverage gate remains mandatory. CHM does not classify canopy species and is not a survey-grade volume product. Host must provide independently co-registered metric rasters and truthful datum. Tests authored, not executed.
