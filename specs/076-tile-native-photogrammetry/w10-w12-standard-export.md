# W10/W12 reference standard export checkpoint
Adds uncompressed LAS 1.2 point format 2, checked integer coordinate scale/offset, quantized bounds, RGB, projected GeoTIFF CRS keys. Photogrammetric points are unclassified single-return placeholders; intensity unavailable, confidence not encoded. No LAZ, COPC, WKT vertical CRS or streaming writer yet. Adds untextured GLB 2.0 terrain mesh export with bounded local positions, UVs and indices, Y-up axis conversion and projected origin/CRS extras. No atlas, normals, materials, georeferenced tileset or arbitrary mesh reconstruction. Both encoders are bounded in-memory reference implementations. Independent LAS/glTF readers and real dataset acceptance still required; unit tests not run.
