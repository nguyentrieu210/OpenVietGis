# Wave 7 — ACP coding agent (advisory)
Base Wave 6 PR #110 at 4b997ef15a3af4b0eb7733ac1586113105b7a936; ACP v1 session initialization, prompt and permission-response patterns adapted from RustGIS assistant/acp.rs at aea84131974b57ff6359666dbe79f88054a64bf1 (Apache-2.0).

- Gateway does not spawn a coding process. Operator must configure exact HTTPS OVG_ACP_RUNNER_URL ending /v1/acp/run, OVG_ACP_RUNNER_KEY (32+ chars), OVG_ACP_AGENTS (comma-separated known IDs), existing subject allowlist. No redirects, caller URLs, arbitrary executable paths or credentials.
- Dedicated separate runner binary ovg-acp-runner listens loopback 9199 behind operator TLS ingress. Must NOT run on GIS VPS. It requires OVG_ACP_ISOLATED_WORKER=1, OVG_ACP_WORK_ROOT, OVG_ACP_AGENTS, OVG_ACP_RUNNER_KEY and explicit absolute preinstalled/pinned adapter executables OVG_ACP_EXEC_CODEX/CLAUDE_CODE/GEMINI/COPILOT/CURSOR/OPENCODE/GOOSE. Codex and Claude paths point to ACP adapters. No npm auto-install or shell.
- **Deployment gate:** enforce external OS/container isolation (non-root, disposable per-run environment, no host mounts, no GIS/network access except required provider endpoints, restricted process tree and resources, provider credentials provisioned only in dedicated worker via operator wrapper). A config flag, ACP denial and empty environment are not a sandbox. Runner is deliberately not deployed automatically.
- Only explicit user text, no GIS data, images, OAuth or MCP token sent. Agent can return unverified advisory text, not edits. All permission requests cancelled, fs/terminal methods denied, no auto mode upgrade. Reject known unsafe/unknown advertised modes. No GIS MCP attachment in this wave, no parent automatic delegation, no follow-up persistent ACP session.
- One running job per remote runner, 120-second process deadline, bounded frames/reports and fixed arguments. Gateway uses async job status, owner-scoped cancellation and permission rechecks. Cancel is best effort; external sandbox must terminate descendants and clean workdir; no automatic retry.
- Tests: handshake, version, denial, foreign-session update and unsafe mode; real external adapters, sandbox/process-tree termination, TLS and provider credentials remain deployment acceptance gates.

Runner maintains a bounded 15-minute in-memory run-ID tombstone for starts and early cancellations; restarts lose tombstones. Added browser mock proving separate ACP consent and text-only payload; native API fixtures reject absent consent and client command fields. A real isolated runner and adapters remain unverified.
