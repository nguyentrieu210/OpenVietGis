# Full GIS AI workspace (candidate)

The existing MCP endpoint remains the same. Production sidecar release `83ac093` now has `OVG_MCP_FULL_TOOLS=1` via `/etc/systemd/system/openvietgis-mcp-public.service.d/50-full-workspace.conf`; 30 Python tests, browser approval/denial fixture, TypeScript and Vite build passed. Real disposable-user Keycloak Authorization Code + PKCE and HTTPS tools/list verified all 17 tools. The new browser handshake prevents full workspace commands until the integrated frontend is released. Roll back by disabling this specific drop-in and restarting the service. The browser must advertise workspace_version=1; older map bridges cannot receive persistent editing commands. OAuth subject and project scope are checked at each browser request, with explicit one-time command consent and exact parameters visible. All data calls go to the existing Core API with the current browser identity and CSRF credentials, never a service/admin credential.

17 MCP tools: live viewport, selection, navigation; list/inspect/read/query layers and features; visible selection, visibility and temporary overlay; create vector layer, schema add/rename, atomic create/update/delete changeset and revert; CAD/spatial operation preview (16 algorithms), topology (6 checks), GeoJSON download. Writes use current source pins where supported, stable operation IDs, backend permission checks, and audit changesets. WGS84 native sources for writes; maximum 100 edits per changeset; bounded tool parameters/results; explicit project ID fixed at pairing. Export is authorized by the Core API and downloaded in the browser.

AI can draw geometry by creating an editable layer and posting a changeset, inspect or preview an operation first, then commit or revert. Attribute updates replace the complete attribute object; AI should read the feature first. CAD preview results are not automatically committed. Query supports typed AST, not arbitrary SQL. Import, raster/hardware, print/layout, plugins and durable processing jobs are not yet AI tools; do not claim entire application parity.

Frontend implementation copied to main's existing `apps/web-next/src/ai-copilot` and connected to LiveStudio first-party bridge. Main contains unrelated uncommitted frontend changes; do not deploy full frontend until approved stable release. Test on a disposable authorized project with real OAuth and browser before promoting writes. Existing production frontend does not yet expose the full panel.
