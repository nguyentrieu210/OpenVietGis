# Hosted provider mode
Set OVG_NAVIGATION_PROVIDER=geoapify and supply OVG_GEOAPIFY_API_KEY_FILE (preferred mounted secret) or OVG_GEOAPIFY_API_KEY in the API runtime only. Default self-hosted mode remains unchanged. Never commit credentials or put them in the client. Geoapify origin is fixed HTTPS; sanitized output only, URL passed through private pipe. A single API process applies a four-request/second window and conservative daily local budget (2000 units, route charged 10), bounded short-lived cache; counters reset on restart, are not distributed and are not billing-credit accounting. Provider plan is authoritative. Suggestions use three characters and 500 ms debounce. Hosted route alternatives are not supported; requests for alternatives return validation error. Routing instructions currently English. Attribution displayed. Real provider direct smoke: Vietnam search, reverse, autocomplete, car/motorcycle routing HTTP 200. Full application build and authenticated end-to-end smoke required before rollout.

## Credential standby
Configure OVG_GEOAPIFY_BACKUP_API_KEY_FILE (preferred) or OVG_GEOAPIFY_BACKUP_API_KEY. A 401 cools down the failed credential for five minutes; the distinct standby may be attempted under the same quota. A 429 stops both keys for 60 seconds, preserving cache hits and never rotating to bypass limits. Missing primary configuration permits the standby under the same local budget. Both credentials share a single per-process budget; not an entitlement or billing meter. Independent provider failover requires separately configured providers and applicable plan authorization; no Geoapify quota splitting.
