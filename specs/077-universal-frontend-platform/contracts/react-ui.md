# W2 React UI contract
Public named exports and compatibility subpath in packages/ui-react. New CSS uses ovg-v2- prefix and W1 variables; no vendor reset. Base UI owns modal/menu/popover/tooltip/tab/toggle interactions; do not mix modal stack with SPEC072 custom manager. Dialog supports controlled open state, sizes, accessible title/description, fixed header/footer and internally scrolling body, but no docking/maximize (W3). Typed forms use label/id and hint/error associations. First-party compatibility subpath preserves old component call signatures; not a third-party security boundary. W0/W1 qualification gates precede active app migration, root lock/workspace integration and vendor notice review.
