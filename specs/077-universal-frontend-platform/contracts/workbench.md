# W3 Workbench contract
Dockview 8.10.0 open-source React adapter; stable host panel registry with persistent map, no untrusted renderers. Host must enforce command and permission checks outside layout. Layout v1 stores only presentation metadata in per-account/project/workspace key, validates known components and IDs, bounded tree and size, rejects popout/edge payloads, falls back to QGIS/map/analysis preset. Registry changes require remount. Same-window floats enabled; native IPC/popouts disabled pending explicit capability negotiation and qualification. No browser window or arbitrary IPC call in W3. Host must veto reset while edits are unsaved; reset may remount, scope change intentionally remounts. Actual map engines, native windows and keyboard drag acceptance remain T301c. Keep SPEC072 DockLayout as production fallback until qualified; no app migration in W3. Compare bundle/performance on same production fixture and lazy-load before activation.
