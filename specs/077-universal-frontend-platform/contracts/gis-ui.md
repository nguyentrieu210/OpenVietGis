# W4 GIS/CAD component contract
Shared React GIS UI exported via ui-react/gis, using W1/W2 tokens and primitives. LayerTree consumes bounded, unique hierarchical host nodes; emits visibility/selection/reorder intents, respects host flags, disables reorder under filter. Group toggle only changes eligible leaves. Legend uses host-computed entries and explicit partial indication; never recomputes renderer classifications. CrsSelector consumes trusted host catalog, no fallback inference. CoordinateInput emits numeric first/second axes with explicit CRS, unit, axis order and absolute/relative mode; absolute geographic bounds checked; no transform or edit mutation. Symbol editor emits validated draft only on Apply; ramp is linear sRGB preview. SnapToolbar sends unit/scope/tolerance/kinds configuration to host; unit change is explicit configuration, not physical conversion; actual snapping engine remains canonical. PropertyEditor emits changed typed fields with entity ID and revision, honors read-only flags, resets draft on changed host version. Host must validate all callbacks and handle permissions, revision conflicts, coordinate correctness, render and edit lifecycle. UI is not an authorization boundary.
Existing layer-tree.ts, layout-legend.ts, crs-display.ts, LayerProperties.tsx, digitizing/SnapMath and CadEditorPanel are reviewed legacy integration targets, not replaced in W4. CSS is class-scoped, no map vendor/print resets. T401c requires actual host adapter and parity verification before activation.
