# Project DEM and local static model preview

## Scope and meaning
- The existing GIS project and its authorization are authoritative; GIS, CAD and 3D are modes of one workspace, not independent copies of project data.
- 3D accepts selected GIS polygon heights in metres, a project raster explicitly declared by the user to be an elevation band, and/or one local static model. No new persistent asset or database record.
- POST /api/v1/organizations/{organization_id}/projects/{project_id}/raster/layers/{layer_id}/terrain-preview requires project read, unrestricted human access and CSRF. Only existing single-band extraction raster layers are eligible. The supplied vertical reference (local, orthometric, ellipsoidal), label, metre unit and explicit acknowledgement are mandatory; metadata is not inferred.
- A bounded offline GDAL subprocess samples the stored raster to an EPSG:3857 regular cell-centre grid (max 128×128, max extent 100 km). Raw metre elevations including negatives are returned; unsupported elevation values, invalid extent and incomplete grids are rejected. Missing samples remain null; only complete quads are triangulated. No external elevation provider, no interpolation across holes. Result is private/no-store, with access and raster existence rechecked after processing.
- Rendering uses the DEM minimum as an origin offset for numerical stability; the displayed range is the unshifted declared elevations. GIS height is relative to sampled terrain at the footprint centre, and missing corner coverage excludes a footprint. This is a flat-base visual extrusion, not a surveyed foundation or terrain-conforming solid. Local model placement uses the selected GIS feature bounding-box centre, sampled elevation (or flat zero absent DEM), user-entered metre offset, scale and clockwise rotation.
- GLB 2.0 or self-contained GLTF 2.0 with one embedded binary buffer; static opaque position/index triangle primitives, node transforms and flat material colour. Max 10 MiB file, 100k triangles, 256 nodes, 10 km model extent after scale. Textures, external URIs, skins, animation, required extensions and unsupported geometry are rejected. No upload or network fetch for model files.
- Mode scope and permission revocation cancel in-flight preparation and dispose alternate rendering; scene configuration is session-local. No model editing, model-specific picking, writeback or project-wide model persistence. GIS source identity and polygon picks remain available.
- This is approximate terrain visualization, not certified vertical datum conversion, survey-grade terrain, BIM authoring, 3D Tiles streaming or photogrammetry. Do not use sampled previews for official level, cut/fill, volume or survey calculations.
