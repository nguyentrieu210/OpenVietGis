# Mode Host Contract
The host creates a session with explicit scope. Request a mode using the current capability and edit/save blockers. If authorized and available, the response exposes a request token; load only that engine. Complete using that same token only after actual readiness, rechecking authorization and edit/save blockers at completion, preserving prior active mode on failure. Scope change must tear down old engine, abort pending I/O, clear camera/selection and ignore obsolete responses. State machine does not grant access: host revalidates server authorization and aborts on revoked access; no forwarding tokens or cross-origin credentials. UI must present disabled reason, pending and failure and be keyboard accessible. GIS mode must restore existing camera and selection retained by host. The ModeCoordinator owns cancellation, prepare/activate/dispose; host calls revalidate on capability changes, updateScope on account/org/project change, and dispose on unmount. PreparedEngine.prepare must avoid modifying the active canvas, activate must attach synchronously, and dispose must be idempotent. The host must make denied data inaccessible immediately even if engine cleanup fails. UI is implemented in packages/spatial-workspace/src/ModeSwitch.tsx; host connection pending.
