# Host and SDK
One canonical command and schema identity; generated clients Rust, TypeScript, Dart, Python, REST, realtime, MCP, declarative and optional WASM/native bridge. Contributions bind exact manifest/release and platform. Web/desktop/mobile declare slots and capabilities; native mobile no dynamic Dart/native download, no arbitrary WebView bridge; unsupported commands hidden/disabled with reason. Signed manifest v1 compatibility unchanged; v2 separate envelope, deterministic canonical JSON signature golden vectors; operator release approval signature separate. Schema validation before render, proposed <=256KiB envelope, <=500 nodes/depth16, <=32 actions, <=10MiB total assets, queue 8/action timeout30s configurable lower by host. Data files independent of plugin entitlement. SDK semver/deprecation and adapter tests; no separate identity or registry.
