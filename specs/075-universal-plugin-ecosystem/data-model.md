# Logical data model (additive; map to existing schema first)
Publisher(id, namespace, verification_state); PublisherKey(publisher_id,kid,public_key,state,validity).
Plugin(existing canonical key,id,owner,category); Release(plugin_id,semver,digest,manifest_digest,host_range,review_state,epoch); Contribution(release_id,host,schema_version,digest); Asset(digest,size,type,storage_ref); Dependency(release_id,target_key,range,optional).
Installation(org_id,project_id,plugin_key,release_id,state,revision); ResolvedLock(installation_id,dependency_release_ids,digest); PermissionGrant(org_id,project_id,actor/role,capability,resource_scope,expiry); Entitlement(org_id,plugin_key,plan,state,valid_until,revision); OfflineLease(scope,release,acl_epoch,expiry,signature).
Review(release_id,reviewer,decision,reason); AuditEvent(actor,tenant,project,action,resource,revision,time,correlation); Job(existing Core job id, scope, plugin release, command, quota, state, output refs).
Commerce: Order, PaymentEvent(provider,event_id UNIQUE), LedgerEntry(immutable debit/credit, currency, minor_units), Refund, Settlement, Payout; independent entitlement transition outbox. No PAN/CVV stored. Tenant scope/RLS on all tenant records; global public metadata separate. Unique release key/version; immutable digest; optimistic revision for installs; idempotency scoped by actor/org/action. Domain records live in domain namespaces and export through approved Core APIs. Never delete on disable.
