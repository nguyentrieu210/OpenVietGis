# Legacy frontend history index

apps/web was retired by Spec 066 after the canonical apps/web-next build,
offline client and real OIDC navigation gates passed. Historical specifications
and QA reports intentionally keep their original paths so accepted evidence is
not rewritten after the fact.

Current architecture and release work must use apps/web-next, packages/client-sdk,
packages/spatial-workspace, docs/architecture.md, Spec 062 and Spec 066.

Historical records that mention apps/web include early platform specs and reports
under docs/qa. Those references describe the repository at the time of the
evidence and are not active runtime or build consumers.

Agent instructions under docs/agents are current instructions and must not direct
new work into the retired tree.
