# Android candidate evidence
The CI debug APK is test-signed only. Its SHA-256, signer fingerprint, stable app ID, native ARM64 PT_LOAD, zip alignment and payload hashes are recorded by inspect_candidate.py. The report deliberately says release_authorized=false, runtime NOT_TESTED. The dependency inventory covers Cargo and Pub, not all native and Gradle libraries or license review.
For actual release: use a reviewed offline-managed release key and approved certificate fingerprint, build signed AAB and APK from checked-in resolved locks, verify bundletool-generated splits and 4/16 KiB alignment, run installed upgrade and device tests, independently rebuild and compare payloads. No release key or signing secret belongs in the repository or CI logs. Do not upload to store or deploy from this candidate workflow. I1 independent.
