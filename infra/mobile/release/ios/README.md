# Independent iOS gate I1
Run on reviewed macOS ARM64 runner with Xcode and Flutter pinned to the candidate. Generate the same FRB bindings and host as Android; validate arm64-apple-ios and arm64-apple-ios-sim dependencies separately. Build simulator and unsigned device candidate. Inspect Mach-O slices, embedded frameworks, permissions, offline launch, data recovery, device MapLibre/FFI/SQLite and upgrade. Device signing and TestFlight/App Store require approved team certificate/provisioning, complete dependency/notice/source review and current store policy. Do not embed production signing credentials. No signed iOS artifact or physical evidence currently supplied. I1 does not block Android A4.
